# Grant-Park-Diorama
An Arduino project focused on demonstrating ways of minimizing light pollution in a diorama of Grant Park. This was made during my time as an Teen participant in the Astro-Science Workshop at the Adler Planetarium in 2021. 

See the instructible on how to build the diorama here: https://www.instructables.com/Grant-Park-Instructable-by-AMN-Lighting-Corp/
